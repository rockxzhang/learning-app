1. 项目概述

张老师随身讲（原名「数字人讲题」）是一款面向信息学奥赛（OI）/算法学习的桌面应用。用户上传一道题目（图片 / PDF / Word / Markdown），应用通过 DeepSeek 视觉大模型 自动：

  1. 生成带逐行注释的 C++ 参考代码（左栏，支持字号 A−/A+ 调节）；
  2. 生成详细解题思路（右上栏：题意分析 / 核心算法 / 复杂度 / 样例推演 / 易错点）；
  3. 由数字人老师在黑板前逐句讲解（右下栏，自然 TTS 男声 + 中文字幕 + 黑板板书）；
并配套：下载代码 / 讲解文档（A4）/ 打印讲解、跨题记忆与个性化、版本升级管理（大/中/小版本）、用户注册登录 / 使用记录 / 管理后台、月度使用 600 次封顶、IP→城市精确地理 等。

5. 核心服务详解

5.1 config.js

持久化配置 DEFAULTs：`llmEndpoint / llmApiKey / llmModel`（DeepSeek 视觉）；`teacherVoice = 'zh-CN-YunxiNeural'`（阳光男声，load() 强制，不被用户覆盖）；`baseVersion`；`updateUrl`；`serverUrl`。

密钥：DeepSeek key 只从环境变量或 services/api.key（gitignore）读取，不入源码；打包时随安装包分发。

5.2 parseFile.js

按文件类型提取题目：图片类转 Base64 + OCR 文本；PDF/Word 解析文本（含图片）；Markdown/文本直读。输出统一结构供 analyze 使用。

5.3 analyze.js

调用 DeepSeek 视觉模型（多轮 prompt，含题目图片/文本），返回 JSON： 

{ title, solution, code(带注释C++), teaching[](逐句讲稿数组), knowledgePoints[] }
通过 response_format=json 保证结构化输出。

5.4 memory.js

跨题记忆：按用户/知识点维度记录已讲解题目与薄弱点，New 讲解时注入上下文实现个性化；profile() / addWeak()。数据存 DATA_DIR 下 JSON。

5.5 screenshot.js

桌面截图：desktopCapturer 抓屏 → 保存至临时目录 → 打开覆盖层框选 → shot:crop 裁剪返回；支持 ESC / 红 ✕ 取消。截取结果作为题目图片送入管线。

5.6 update.js

版本升级管理核心：parse()/type() 比较 major(大)·minor(中)·patch(小)；check(url,cur) 拉取 manifest 判断；download(url,dest,onProgress) 流式下载带进度。

类型判定行为
大版本主版本不同整包重装：下载→安装目录建 update/→拉起安装→关软件
中版本次版本不同差分安装：下载→拉起安装→关软件
小版本修订号不同热更：仅进度条→完成刷新（无真实下载）

5.7 account.js

注册/登录/使用记录，连接后端：register/login/record/info；会话存 DATA_DIR/session.json，登录态持久化；record() 由讲解成功后自动调用（主进程 fire-and-forget），上报 IP/城市/时间/累计次数。

6. 讲解管线（数据流）

点「开始讲解」(需已登录 + 未达月度上限)
  → parseFile 提取题目
  → analyze 调 DeepSeek 视觉 → code/solution/teaching/knowledgePoints
  → tts.synthesize ×N 段 → 逐段 mp3 (目录 tts/)
      (校验通过后自动调用 account.record 上报一条使用)
  → renderer: renderCode(带行号) / renderSolution / renderTranscript
  → 播放：loadSegment →

7. 语音合成（Edge TTS）

纯 Node 实现微软 Edge TTS：WebSocket 到 wss://speech.platform.bing.com/.../edge/v1，带 Sec-MS-GEC 签名头 + MUID cookie，每段发 SSML，收 audio 二进制。openSession(voice,ratePct) 复用一条连接逐段合成，规避连续建连被限流；send() 增超时；synthesize() 逐段重试 + 会话断线重开续传（reopenLimit），不丢段；管线再整段整体重试×3，杜绝「组到一半中断」。

8. 版本升级管理

界面：版本号旁红点（有更新）→ 点击弹「软件更新」（当前/最新版本、更新类型、更新内容、开始更新、进度条）。打包时读 release/changelog.txt（UTF-8）→ 写 release/update-manifest.json（latest/changelog/downloadUrl/sizeMb），供后台使用。模拟后台 mock-update-server.js 读 manifest 或环境变量（LATEST_VERSION/CHANGELOG/FILE）切换大/中/小场景。本地验证：npm run updatetest。

9. 用户系统与管理后台

客户端：头部「注册/登录」→ 弹窗；注册填用户名（工信部违规名单校验→提示「违规」；重复→「用户名重复」）/ 手机号（尾数校验，无短信）/ 密码/确认密码；登录（用户名或手机号+密码）；登录态持久化；「我的信息」看累计次数/本月使用x/上限；未登录用任何功能（讲解/截图/下载/打印）先提示登录。

后端：server/server.js，POST /api/register|login|usage|info，GET /api/admin/*。管理后台登录（zhangxin/jackyso5 固定），/admin 与 /api/admin/* 未登录拦截；登录成功写 admin_token cookie，location.reload() 原地刷新（不跳回 OJ）。月度封顶：MONTH_LIMIT（默认 600）。

16. 已知问题与说明

  • Edge TTS 稳定性：间歇性掉线/空音频已用「会话复用+重试+超时+断线续传+整体重试」加固，偶发的限流仍可能触发，失败时界面给出明确提示。
  • IP→城市：使用 ip2region 离线库精确到市；回环/内网返回「本地（回环）」。
  • 中文参数编码：PowerShell→npm 传中文参数会乱码，更新内容用 release/changelog.txt 文件传递。
  • 密钥：DeepSeek key 仅存 services/api.key（gitignore），打包时随应用分发；泄露需及时轮换。
  • 管理后台鉴权：固定账号 zhangxin/jackyso5，token 存内存（重启失效），生产建议改造为持久化会话。
  • 月度封顶：按 MONTH_LIMIT（默认600），达到后接口返回提示并拦截。
